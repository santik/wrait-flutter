# US-010: Network Availability Check

## Description
As the app, I want to check network availability before attempting cloud
recording in Best mode.

## Specifications

- Use `connectivity_plus` package (or platform connectivity check).
- Before starting recording in Best mode:
  - Call `canAttemptCloudUpload()`.
  - If no connectivity: emit `ConnectionRequired` error immediately without
    starting recording or saving a draft.
- This is a pre-flight check only; actual network failures during upload are
  handled by the draft system (US-015).
- Offline mode: no network check needed.

## Reference

- `data/device/NetworkAvailability.kt` — `canAttemptCloudUpload()` interface.
- `MainRecordingController.kt` line 110-115 — pre-flight check before
  entering Listening state.

## Acceptance Criteria

- [ ] No-network detected before recording start in Best mode.
- [ ] "best mode needs connection" error shown (no draft saved).
- [ ] Offline mode completely unaffected by network state.
