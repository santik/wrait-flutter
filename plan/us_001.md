# US-001: Flutter Project Setup & Architecture

## Description
As a developer, I want to set up the Flutter project with the correct
architecture, dependencies, and folder structure so that all subsequent stories
can be built on a solid foundation.

## Specifications

- Create Flutter project targeting Android (minSdk 26) and iOS (14+).
- State management: Riverpod (or BLoC).
- Navigation: GoRouter.
- Folder structure:
  ```
  lib/
    core/         # constants, theme, design tokens, utils
    data/         # repositories, API clients, local DB
    domain/       # models, use cases
    presentation/ # screens, widgets, controllers
    app.dart      # MaterialApp + router
    main.dart     # entry point
  ```
- Add dependencies:
  - `flutter_secure_storage`
  - `sqflite_sqlcipher` or `drift`
  - `dio` (HTTP client)
  - `permission_handler`
  - `local_auth`
  - `record` or `flutter_sound`
  - `speech_to_text`
  - `share_plus`
  - `path_provider`
  - `connectivity_plus`
  - `wakelock_plus`
- Configure platform-specific settings:
  - Android: `minSdkVersion 26`, `RECORD_AUDIO` permission in manifest.
  - iOS: `NSMicrophoneUsageDescription`, `NSSpeechRecognitionUsageDescription`.
- Set up environment configuration (backend URL, proxy secret, recording hard
  cap) via `--dart-define` or `.env` file.
- Add linting rules (very_good_analysis or flutter_lints).

## Reference

- Build config: `wrait-android/build.gradle.kts` (minSdk 26, targetSdk 34).
- Env values from `wrait-android/local.properties`: BACKEND_URL, PROXY_SECRET,
  RECORDING_HARD_CAP_MS (default 120000), PRIVACY_MODE.

## Acceptance Criteria

- [ ] `flutter run` launches on both Android emulator and iOS simulator.
- [ ] All declared dependencies resolve without conflicts.
- [ ] Folder structure matches specification.
- [ ] Environment variables are accessible at runtime.
- [ ] Lint rules pass with zero warnings on empty project.
