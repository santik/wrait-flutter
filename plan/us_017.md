# US-017: Settings Panel and Privacy Mode Toggle

## Description
As a user, I want to switch between Best and Offline modes from a settings
panel.

## Specifications

- Trigger: settings gear icon (top-right) or swipe-down (> 80dp) on main screen.
- Not accessible during active recording (icon hidden, swipe disabled).
- Panel slides in from top with 300ms animation.
- Full-screen overlay with:
  - Scrim (tap to dismiss).
  - Surface panel (anchored to top) containing:
    - "Offline mode" row with description subtitle + Switch toggle.
      - Switch ON = MODE_OFFLINE, Switch OFF = MODE_BEST.
    - Language row (only visible when Offline mode active):
      - Shows current language name + " / used only in offline mode".
      - Tappable — dismisses panel then opens language sheet.
    - Drag handle at bottom (visual affordance).
- Dismiss: tap scrim, or swipe-up on panel (> 40px upward drag).
- Mode change saved immediately, takes effect on next recording.

## Reference

inside `wrait-android/src/main/java/com/wrait/app` directory
- `ui/settings/SettingsPanel.kt` — full panel UI with slide animation,
  scrim, swipe-to-dismiss, conditional language row.

## Acceptance Criteria

- [ ] Panel slides in/out with animation.
- [ ] Toggle switches privacy mode and persists immediately.
- [ ] Language row visible only in Offline mode.
- [ ] Scrim tap and swipe-up both dismiss panel.
- [ ] Panel not accessible during active recording.
