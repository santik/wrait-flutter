# US-020: Screenshot and Screen Recording Prevention

## Description
As a user, I want screenshots and screen recording blocked to protect my
diary content from being captured.

## Specifications

- Android: set `FLAG_SECURE` on window on app launch (before content renders).
  This blocks screenshots, screen recording, and hides recent apps thumbnail.
- iOS: implement equivalent protection (secure UITextField overlay technique
  or screen capture notification to hide content).
- Must be set before any sensitive content is displayed.

## Reference

inside `wrait-android/src/main/java/com/wrait/app` directory
- `MainActivity.kt` line 107:
  `window.addFlags(android.view.WindowManager.LayoutParams.FLAG_SECURE)`

## Acceptance Criteria

- [ ] Screenshots produce blank/black image on Android.
- [ ] Recent apps shows blank thumbnail on Android.
- [ ] Screen recording blocked or content hidden on iOS.
- [ ] Protection active from first frame.
