# US-013: Entry List Screen

## Description
As a user, I want to view all my diary entries in a scrollable list.

## Specifications

- Navigation: swipe-up on main screen or tap stats line.
- Entries sorted by `createdAt` descending (newest first).
- Each row displays:
  - Day of week (short) + formatted date + time (locale-aware).
  - First line of `cleanedText` (or `rawTranscript` if no cleanup), single line,
    ellipsis overflow.
  - Language display name (only if different from device default).
- Swipe-to-delete:
  - Swipe right reveals 80dp red delete area with trash icon.
  - Anchored draggable (not free-form).
  - Tap revealed delete button triggers confirmation dialog.
- Delete confirmation: standard alert dialog with Cancel/Delete actions.
- Empty state: centered "no entries yet" text.
- Back navigation: back button (top-left) or swipe-down gesture.
- Haptic feedback on swipe-to-delete reveal.

## Reference

inside `wrait-android/src/main/java/com/wrait/app` directory
- `ui/entries/EntryListScreen.kt` — full list implementation with
  AnchoredDraggableState for swipe-to-delete.
- `ui/entries/EntryListViewModel.kt` — state management.

## Acceptance Criteria

- [ ] Entries display in reverse chronological order.
- [ ] Swipe-to-delete works with anchored reveal and confirmation.
- [ ] Empty state shown when no entries exist.
- [ ] Tap navigates to entry detail.
- [ ] Back navigation works (button and swipe-down).
- [ ] Date formatting is locale-aware.
