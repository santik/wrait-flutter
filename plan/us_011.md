# US-011: Main Screen UI

## Description
As a user, I want the main screen with the action button, status line, stats
line, and quota display.

## Specifications

- Layout (vertically centered stack):
  - Quota line: "{limit} total / {remaining} left" (Best mode only, hidden if no quota).
  - Action button: circular, adaptive size (screenWidth * 0.56, clamped 160-280dp).
  - Status line (below button): animated text crossfade based on state.
  - Stats line (below status): "{count} entries / {days} days >" — tappable.
- Action button behavior:
  - Label per state: "tap to write" (Idle, first time: "tap button to write"),
    "listening..." (Listening), "uploading..." (Uploading),
    "cleaning up..." (Processing), no label change on Saved/Error.
  - Pulse ring animation: plays during Listening (scale 1.0 to 1.6, alpha 0.6 to 0, 1800ms loop).
  - Countdown ring: arc drawn in last 10s of hard cap showing remaining time.
  - Shake animation: horizontal oscillation on TooShort/NoMatch.
  - Alpha: 1.0 normal, 0.3 during Processing/Uploading (disabled feel).
- Settings icon: top-right corner, hidden during active recording.
- Gestures:
  - Swipe-up (> 80dp): navigate to entry list.
  - Swipe-down (> 80dp): open settings panel.
- Status line tap actions:
  - "tap to read" -> navigate to saved entry detail.
  - "mic blocked..." -> open OS app settings.
  - "tap button to write" -> trigger recording (same as button tap).
- Stats line tap: navigate to entry list.

## Reference

inside `wrait-android/src/main/java/com/wrait/app` directory
- `ui/main/MainScreen.kt` — layout composition and gesture handling.
- `ui/main/ButtonArea.kt` — button rendering, pulse, countdown, shake.
- `ui/main/PulseRing.kt` — pulse ring animation.

## Acceptance Criteria

- [ ] Button renders at correct adaptive size on various devices.
- [ ] All recording states display correct label and alpha.
- [ ] Pulse animation plays during Listening.
- [ ] Countdown ring appears in last 10s of hard cap.
- [ ] Shake fires on TooShort/NoMatch errors.
- [ ] Swipe gestures trigger correct navigation.
- [ ] Stats line shows correct counts and navigates to entry list.
- [ ] Quota line visible only in Best mode with valid quota data.
