# US-006: Audio Recording Service

## Description
As a user, I want the app to record my voice when I tap the button so that it
can be transcribed.

## Specifications

- Cross-platform audio recording (use `record` package or similar).
- Record to WAV or AAC file in app temporary directory.
- Configuration:
  - Sample rate: 16kHz (optimal for speech recognition).
  - Channels: mono.
  - Hard cap: from env config (default 120s), auto-stop on reaching cap.
- Service interface:
  - `startRecording(outputPath)` — begins recording.
  - `stopRecording()` — returns file path of recorded audio.
  - `isRecording` — current state.
  - Report `hardCapDeadlineElapsedRealtime` when recording starts (for UI
    countdown).
- Audio file lifecycle:
  - Deleted immediately after successful transcription.
  - Kept on disk for draft retry on failure.

## Reference

- `data/speech/RecognitionConfig.kt` — HardCapMs (120000ms default),
  CountdownWindowMs (min of 10000 and HardCapMs).
- Cloud mode records to file then uploads; offline mode uses streaming STT.

## Acceptance Criteria

- [ ] Audio records successfully on Android and iOS.
- [ ] Hard cap auto-stops recording at configured duration.
- [ ] Output file is valid audio playable by standard tools.
- [ ] Recording stops cleanly on `stopRecording()`.
- [ ] Temporary files cleaned up after successful processing.
