# US-002: Theme, Design Tokens & Core UI Shell

## Description
As a user, I want the app to have a clean minimal theme matching the original
wrait design so the experience feels familiar.

## Specifications

- Implement design tokens:
  - Animation: fade 300ms, pulse 1800ms, button alpha 200ms, delete fade 200ms.
  - Spacing: xs=4, sm=8, md=16, lg=24, xxl=48.
  - Gesture thresholds: swipe nav 80dp, swipe delete reveal 80dp.
  - Button: ratio 0.56, min 160dp, max 280dp, pulse scale 1.6.
  - Status line: clear delay 4000ms, reserved height 48dp.
  - Quota line: reserved height 48dp.
- Material 3 theme with light mode.
- Typography: bodyLarge, labelLarge, bodySmall, titleMedium.
- Create app shell with GoRouter: routes for `/`, `/entries`, `/entry/:id`.

## Reference

- `ui/theme/DesignTokens.kt` — all numeric constants.
- `ui/theme/Theme.kt`, `Color.kt`, `Type.kt` — Material 3 theming.

## Acceptance Criteria

- [ ] Theme renders correctly on Android and iOS.
- [ ] Design tokens are centralized and reusable.
- [ ] Navigation between routes works (empty placeholder screens).
- [ ] Adaptive button size calculated correctly for various screen widths.
