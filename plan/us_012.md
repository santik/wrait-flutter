# US-012: Microphone Permission Handling

## Description
As a user, I want the app to handle microphone permissions gracefully on both
platforms.

## Specifications

- Use `permission_handler` package.
- On first button tap when permission not granted:
  - Request RECORD_AUDIO (Android) / microphone (iOS) permission.
  - Track analytics event: microphone_permission_requested.
- If granted: proceed with recording.
- If denied (not permanently): allow retry on next tap.
- If permanently denied (Android: "Don't ask again" selected):
  - Show "mic blocked / tap to open settings" status.
  - Tapping status line opens OS app settings page.
  - Track analytics event: microphone_permission_permanently_denied.
- On iOS: also need speech recognition permission for offline mode.
- Monitor permission on app resume (foreground return):
  - If permission newly granted: clear blocked state.
  - If permission revoked mid-recording: stop recording, show error.

## Reference

inside `wrait-android/src/main/java/com/wrait/app` directory
- `MainActivity.kt` lines 160-270 — permission request flow,
  `isMicrophonePermissionPermanentlyDenied()` logic, settings intent.

## Acceptance Criteria

- [ ] Permission requested on first recording attempt.
- [ ] Permanently denied state detected and settings link works.
- [ ] Permission grant on return from settings clears blocked state.
- [ ] Revocation during recording stops recording safely.
- [ ] Works correctly on both Android and iOS.
