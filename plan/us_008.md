# US-008: Transcript Cleanup Use Case

## Description
As a user in Best mode, I want my raw transcript cleaned up by AI to remove
filler words and fix punctuation.

## Specifications

- CleanupTranscriptUseCase calls backend `/api/cleanup`.
- Input: raw transcript text + language code.
- Output: CleanupResult.Success(cleanedText, quota) or
  CleanupResult.Failure(reason, quota).
- On success: update entry with cleaned text and recalculated word count.
- On failure: entry remains as draft (isDraft=true) with raw transcript only.
- Word count: split cleaned text on whitespace, count non-empty tokens.
- Max transcript length before calling cleanup: 10,000 characters (truncate
  if longer).

## Reference

- `domain/usecase/CleanupTranscriptUseCase.kt` — use case implementation.
- `data/api/TranscriptCleanupServiceImpl.kt` — calls WraitBackendClient.
- `MainRecordingController.kt` line 335: MAX_TRANSCRIPT_LENGTH = 10,000.

## Acceptance Criteria

- [ ] Cleanup call succeeds and entry updated with cleaned text.
- [ ] On failure, entry stays as draft for retry.
- [ ] Word count correctly calculated from cleaned text.
- [ ] Quota updated from response (null quota does not overwrite previous).
- [ ] Transcripts over 10,000 chars handled gracefully.
