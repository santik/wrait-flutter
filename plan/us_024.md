# US-024: On-Device Transcription Service (Offline Mode)

## Priority
Lower priority — implement after Best mode is fully functional.

## Description
As a user in Offline mode, I want on-device speech recognition so my voice
never leaves my phone.

## Specifications

- Use `speech_to_text` package with on-device models.
- Flow:
  1. Check if offline model is available for selected language.
  2. Start listening, emit RecordingStarted with hard cap deadline.
  3. Accumulate partial/final results across silence restarts.
  4. On user stop or hard cap, emit RecordingEnded, return full transcript.
- No cleanup step (raw transcript saved directly as final entry, isDraft=false).
- Silence handling:
  - 5s silence timeout triggers auto-restart of recognizer.
  - Minimum 2s utterance before considering silence.
  - Up to 100 restart attempts (covers ~2.5 min of intermittent speech).
- Report ModelNotAvailable error if offline model not installed for language.
- On iOS: requires speech recognition permission in addition to microphone.

## Reference

inside `wrait-android/src/main/java/com/wrait/app` directory
- `data/speech/SpeechRecognizerManager.kt` — Android SpeechRecognizer wrapper
  with restart logic and partial result accumulation.
- `data/speech/RecognitionConfig.kt` — SilenceTimeoutMs=5000,
  MinimumUtteranceMs=2000, MaxRestartAttempts=100.

## Acceptance Criteria

- [ ] On-device transcription works without network on both platforms.
- [ ] Language selection respected (uses selectedLanguage preference).
- [ ] Missing offline model shows "no offline model for {language}" error.
- [ ] Silence auto-restart keeps session alive for long spoken entries.
- [ ] Hard cap stops recording and returns accumulated transcript.
- [ ] Entry saved directly without cleanup (isDraft=false, cleanedText=null).
