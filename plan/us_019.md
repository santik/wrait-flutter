# US-019: App Lock (Biometric/Device Credential)

## Description
As a user, I want the app to require biometric or device credential
authentication when returning from background to protect my diary.

## Specifications

- Use `local_auth` package.
- On app going to background (process stop): mark as locked.
- On returning to foreground (process start):
  - Check biometric/device credential availability.
  - If available: blur content (20dp Gaussian blur), show lock screen overlay.
  - Lock screen: "Unlock" button that triggers auth prompt.
- Authentication outcomes:
  - Success: remove blur, dismiss lock screen.
  - Cancelled: remain locked, user can tap Unlock again.
  - Error (no security configured): show message prompting user to set up
    device security + button to open security settings.
  - Error (temporarily unavailable): show appropriate message.
- Auth prompt only launched when lifecycle is RESUMED (avoid re-triggering
  during transitions).

inside `wrait-android/src/main/java/com/wrait/app` directory
- `lock/AppLockAuthenticator.kt` — interface with availability(), authenticate(), cancel().
- `lock/AppLockViewModel.kt` — state management (shouldBlockContent, isPromptPending).
- `MainActivity.kt` lines 88-140 — ProcessLifecycleOwner integration,

## Acceptance Criteria

- [ ] Content blurred immediately when app goes to background.
- [ ] Biometric/credential prompt shown on return to foreground.
- [ ] Successful auth removes blur and lock screen.
- [ ] Cancel keeps app locked until next unlock attempt.
- [ ] Missing device security handled with settings link.
- [ ] Works on Android (BiometricPrompt) and iOS (Face ID / Touch ID).
