# US-021: Keep Screen On During Recording

## Description
As a user, I want the screen to stay on while recording so my device does not
lock mid-entry.

## Specifications

- When recording state becomes active (Listening, Uploading, or Processing):
  acquire wakelock / set keep-screen-on flag.
- When recording state returns to non-active (Idle, Saved, Error, Deleted):
  release wakelock / clear keep-screen-on flag.
- Only add flag if not already set; only clear if currently set (idempotent).
- Clean up on app close (release wakelock).

## Reference

- `MainActivity.kt` `KeepScreenOnCommand` enum and `keepScreenOnCommand()` function —
  idempotent flag management based on `isRecordingActive` and current flag state.

## Acceptance Criteria

- [ ] Screen stays on during entire recording session.
- [ ] Screen timeout resumes after recording completes.
- [ ] Flag cleared on app close.
- [ ] Works on both platforms.
