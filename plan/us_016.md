# US-016: Device Registration

## Description
As the app, I want to register an anonymous device ID with the backend on
launch for beta access gating and quota tracking.

## Specifications

- On app launch (before draft retry):
  1. Get or create device ID (UUID, SHA-256 hashed, stored encrypted).
  2. Call `POST /api/register` with device ID.
  3. On success: extract quota from response, update quota state.
  4. On failure: log warning, continue without blocking.
- Retry: up to 3 attempts with exponential backoff on transient errors
  (5xx, timeouts). Non-retryable on 4xx.

## Reference

inside `wrait-android/src/main/java/com/wrait/app` directory
- `domain/usecase/RegisterDeviceUseCase.kt` — orchestrates registration.
- `data/api/WraitBackendClient.kt` `register()` — retry logic with
  `shouldRetryRegisterHttp()` and backoff delays.
- `data/device/DeviceIdProvider.kt` — device ID generation and storage.

## Acceptance Criteria

- [ ] Registration called on every app launch.
- [ ] Quota updated from successful response.
- [ ] Failure does not block app usage.
- [ ] Device ID stable across launches.
- [ ] Transient errors retried up to 3 times.
