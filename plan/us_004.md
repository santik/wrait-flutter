# US-004: Preferences Storage

## Description
As a user, I want my settings (language, privacy mode, device ID) persisted
securely between app launches.

## Specifications

- Use `shared_preferences` for non-sensitive prefs:
  - `selectedLanguage` (String, default from device locale or "en-US")
  - `privacyMode` ("MODE_BEST" or "MODE_OFFLINE")
  - `hasEverRecorded` (bool)
- Use `flutter_secure_storage` for sensitive values:
  - `deviceId` (SHA-256 hashed UUID)
- PreferencesRepository interface:
  - `selectedLanguage` returns Stream<String>
  - `setLanguage(code)`
  - `privacyMode` returns Stream<PrivacyMode>
  - `savePrivacyMode(mode)`
  - `seedPrivacyModeOnce(default)` — write only if never set before
  - `hasEverRecorded` returns Stream<bool>
  - `setHasEverRecorded()`
  - `getOrCreateDeviceId()` returns String
- Language default resolution: match device locale to supported list, fallback
  "en-US".

## Reference

- `domain/repository/PreferencesRepository.kt` — interface definition.
- `domain/model/SupportedLanguages.kt` — `defaultSupportedLanguageCode()` logic.

## Acceptance Criteria

- [ ] Language preference survives app restart.
- [ ] Privacy mode preference survives app restart.
- [ ] Device ID generated once, never changes across launches.
- [ ] Default language derived from device locale with fallback to "en-US".
