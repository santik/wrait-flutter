# US-014: Entry Detail Screen

## Description
As a user, I want to view the full text of a diary entry with options to share
or delete it.

## Specifications

- Header row: back button (left), share icon + delete icon (right).
- Content (scrollable):
  - Day of week + full formatted date.
  - Word count display.
  - Full entry text: `cleanedText` if available, otherwise `rawTranscript`.
- Text is selectable (for copy).
- Share button: opens native share sheet with shareable text (cleaned entry).
  - Handle ActivityNotFoundException gracefully (show toast).
- Delete button: shows confirmation dialog, on confirm deletes entry and
  navigates back to entry list.
- Swipe-down gesture (overscroll > 80dp): triggers back navigation.
- On back: flush any pending edits (future edit feature).

## Reference

inside `wrait-android/src/main/java/com/wrait/app` directory
- `ui/entries/EntryDetailScreen.kt` — full detail layout, share intent,
  delete dialog, swipe-back via NestedScrollConnection.
- `ui/entries/EntryDetailViewModel.kt` — entry loading, delete, edit state.

## Acceptance Criteria

- [ ] Full entry text displayed correctly.
- [ ] Share opens native share sheet on both platforms.
- [ ] Delete with confirmation dialog works and navigates back.
- [ ] Back navigation via button and swipe-down gesture.
- [ ] Word count displayed correctly.
- [ ] Text is selectable/copyable.
