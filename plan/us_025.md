# US-025: Language Selection (Offline Mode)

## Priority
Lower priority — implement alongside or after US-024 (Offline transcription).

## Description
As a user in Offline mode, I want to select my transcription language from
a list of supported options.

## Specifications

- Modal bottom sheet displaying supported languages.
- Supported languages (code + display name):
  - en-US: English
  - nl-NL: Nederlands
  - ru-RU: Русский
  - uk-UA: Українська
  - de-DE: Deutsch
  - es-ES: Español
  - fr-FR: Français
  - it-IT: Italiano
  - pl-PL: Polski
  - pt-PT: Português
  - tr-TR: Türkçe
- Current language indicated with radio button (selected state).
- Tap language row: select it, dismiss sheet.
- Only accessible in Offline mode (in Best mode, backend auto-detects language).
- Default language resolution: match device locale tag to supported list by
  base language code; fallback "en-US".
- Language row in settings panel (US-017) triggers this sheet only when
  Offline mode is active.

## Reference

- `domain/model/SupportedLanguages.kt` — SUPPORTED_LANGUAGES list,
  `defaultSupportedLanguageCode()`, `resolveSupportedLanguageCode()`.
- `ui/main/LanguageSettingsSheet.kt` — bottom sheet with RadioButton list.

## Acceptance Criteria

- [ ] All 11 languages listed with correct display names.
- [ ] Selection persisted and used for next Offline recording.
- [ ] Sheet only openable when Offline mode is active.
- [ ] Current selection visually indicated with radio button.
- [ ] Default correctly derived from device locale.
